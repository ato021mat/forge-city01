# Forge City v2.1

کاراکتر بساز → در شهر تایل‌مپ‌محور زندگی کن → شغل واقعی انجام بده.

## جدید در ۲.۱
- سیستم تایل‌مپ Canvas (procedural + پشتیبانی اسپرایت پیکسل)
- AudioManager با Howler (SFX + موسیقی)
- manifest پک‌های رایگان Kenney / itch.io
- راهنمای دانلود دارایی‌ها
- دو راهنمای کامل: از صفر / اصلاح نسخه قبلی

## اجرا
```bash
npm install && npm run dev
```
