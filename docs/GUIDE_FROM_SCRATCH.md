# راهنمای کامل پیاده‌سازی از صفر – Forge City v2.1

این راهنما برای کسی است که پروژه را از صفر روی سیستم خودش راه می‌اندازد.

---

## پیش‌نیاز
- Node.js نسخه ۱۸ یا بالاتر (`node -v`)
- npm یا yarn
- مرورگر کروم/فایرفاکس
- (اختیاری) حساب itch.io و مرور سایت Kenney.nl برای دانلود رایگان

---

## مرحله ۱: نصب و اجرا

```bash
unzip Forge_City_v2.1_Complete.zip
cd v2.1
npm install
npm run dev
```

آدرس: http://localhost:3000

اولین صفحه = **ساخت کاراکتر**. بعد از ساخت، نقشه شهر و شغل‌ها باز می‌شود.

## مرحله ۳: جریان بازی (منطق)

1. کاربر ظاهر کاراکتر را می‌سازد (بدن، صورت، مو، لباس، فانتزی).
2. کاراکتر در `localStorage` با کلید `forge-city-v2` ذخیره می‌شود.
3. نقشه تایل‌مپ شهر نمایش داده می‌شود؛ کاراکتر روی منطقه فعلی است.
4. با کلیک روی منطقه، جابه‌جا می‌شود (اگر سطحش باز باشد).
5. در تب «کارها» شغل‌های همان منطقه را می‌بیند و وارد مینی‌گیم می‌شود.
6. عملکرد بهتر در مینی‌گیم = پاداش بیشتر.

---

## مرحله ۴: اضافه کردن اسپرایت پیکسل (حجم واقعی)

بدون اسپرایت هم بازی کار می‌کند (تایل رنگی procedural).

با اسپرایت:
1. فایل `scripts/DOWNLOAD_ASSETS.md` را باز کن.
2. از Kenney یا itch پک رایگان را دانلود کن.
3. PNGها را در `public/sprites/tiles/` با نام‌های مشخص بگذار.
4. صفحه را رفرش کن؛ اگر لود شود گوشه نقشه می‌نویسد «اسپرایت لود شد».

همین کار حجم پروژه را به چند مگابایت می‌رساند.

---

## مرحله ۵: صدا و موسیقی

1. طبق `scripts/DOWNLOAD_ASSETS.md` فایل‌های ogg را در `public/audio/` بگذار.
2. `AudioManager` خودش از Howler استفاده می‌کند.
3. اگر فایل نباشد، بازی بدون صدا ادامه می‌دهد (کرش نمی‌کند).

در کد:
- ورود به شهر → `playMusic('city')`
- شروع شغل → `playSfx('work_start')` + موسیقی work

---

## مرحله ۶: تایل‌مپ

- تعریف تایل‌ها: `src/lib/world/tilemap.ts`
- رندر: Canvas در `TilemapView.tsx`
- اندازه تایل: ۳۲ پیکسل
- نقشه: ۲۰×۱۵ تایل procedural

برای بزرگ‌تر کردن نقشه: `MAP_W` و `MAP_H` را عوض کن و حلقه `generateCityMap` را گسترش بده.

## عیب‌یابی سریع

| مشکل | راه‌حل |

| صفحه سفید | کنسول مرورگر را ببین؛ معمولاً import اشتباه |
| کاراکتر ذخیره نمی‌شود | localStorage را پاک نکن؛ کلید `forge-city-v2` |
