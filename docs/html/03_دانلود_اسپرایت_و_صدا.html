دانلود اسپرایت پیکسل، صدا و تایل‌مپ

بازی بدون این فایل‌ها هم کار می‌کند. این‌ها فقط ظاهر و صدا را بهتر می‌کنند. همه رایگان‌اند.

هیچ برنامه‌ای نصب نکن. فقط از مرورگر دانلود کن و فایل‌ها را در GitHub داخل پوشه بازی آپلود کن.

۱) تایل و تصویر شهر (اسپرایت پیکسل)

یکی از این سایت‌ها را باز کن و فایل رایگان را دانلود کن:

  • Kenney – RPG Urban Pack (کاملاً رایگان و آزاد)
  • سایر پک‌های Kenney
  • پک شهر ۳۲×۳۲ در itch.io

بعد از دانلود و باز کردن زیپ، عکس‌های PNG را در گیت‌هاب اینجا بگذار:

public/sprites/tiles/

اگر بتوانی اسم فایل‌ها را نزدیک این‌ها بگذاری بهتر است:

اسم پیشنهادیموضوع
grass.pngچمن
road.pngجاده
sidewalk.pngپیاده‌رو
building_01.pngساختمان
tree.pngدرخت
water.pngآب

اگر اسم فرق داشت، بعداً می‌توانی در کد مسیر را عوض کنی؛ یا فعلاً همان procedural رنگی را استفاده کن.

۲) صداهای کوتاه (کلیک، سکه و …)

  • Kenney Interface Sounds
  • Kenney RPG Audio

فایل‌های صوتی را اینجا آپلود کن:

public/audio/sfx/

اسم‌های مفید:

click.ogg · confirm.ogg · error.ogg · success.ogg · coin.ogg

فرمت mp3 یا wav هم اغلب کار می‌کند.

۳) موسیقی پس‌زمینه

  • OpenGameArt → جستجو کن: town music یا city loop

بگذار در:

public/audio/music/

مثلاً: city_theme.ogg و work_theme.ogg

۴) ترتیب کار در GitHub

  1. فایل را از سایت رایگان دانلود کن.
  2. زیپ را روی ویندوز Extract کن.
  3. در مخزن GitHub بازی، برو داخل پوشه مناسب (public/...).
  4. Upload files و فایل‌ها را بکش داخل صفحه.
  5. Commit کن.
  6. اگر با Cloudflare یا Vercel منتشر کرده‌ای، یک بار دوباره Deploy می‌شود و ظاهر/صدا به‌روز می‌شود.
یادت باشد: تا وقتی این فایل‌ها را نگذاری، بازی خاموش نمی‌شود؛ فقط نقشه ساده‌تر و بدون صدا است.
