راهنمای از صفر – بازی Forge City

این راهنما برای کسی نوشته شده که می‌خواهد بدون نصب هیچ برنامه‌ای روی لپ‌تاپ، بازی را راه بیندازد.

خلاصه خیلی کوتاه:
فایل بازی را در سایت StackBlitz باز می‌کنی → بازی در همان مرورگر اجرا می‌شود → بعداً رایگان منتشرش می‌کنی.

۱ فایل بازی را داشته باش

فایل زیپ بازی را که دریافت کرده‌ای نگه دار. اسمش چیزی شبیه این است:

Forge_City_v2.1_Complete.zip

داخلش پوشه‌ای به اسم v2.1 هست. همان پوشه اصل بازی است.

۲ بازی را آنلاین اجرا کن (بدون نصب)

از سایت StackBlitz استفاده می‌کنیم. رایگان است و نیازی به نصب ندارد.

روش آسان:

  1. به این آدرس برو: https://stackblitz.com
  2. اگر خواستی حساب رایگان بساز (با گوگل هم می‌شود). بعضی کارها بدون حساب هم ممکن است.
  3. روی Open Web Container یا ساخت پروژه جدید برو.
  4. بهترین حالت: یک بار پروژه را در GitHub رایگان آپلود کن، بعد در StackBlitz با «Import from GitHub» باز کن.
روش ساده‌تر با GitHub (پیشنهادی):
  1. برو به github.com و یک حساب رایگان بساز.
  2. روی New repository بزن. یک اسم بگذار مثلاً forge-city.
  3. فایل‌های داخل پوشه v2.1 را در همان مخزن آپلود کن (دکمه Add file → Upload files).
  4. بعد برو به: stackblitz.com/github
  5. آدرس مخزن گیت‌هاب خودت را بده تا پروژه باز شود.
  6. صبر کن تا نصب تمام شود. بعد بازی در همان صفحه اجرا می‌شود.

اگر StackBlitz خطا داد، از CodeSandbox هم می‌شود همین کار را کرد: Import from GitHub.

۳ بازی را بازی کن

  1. اول صفحه «ساخت کاراکتر» می‌آید.
  2. ظاهر کاراکتر را عوض کن (مو، لباس، رنگ و …).
  3. یک اسم بگذار و وارد شهر شو.
  4. روی نقشه، منطقه را انتخاب کن.
  5. از تب «کارها» یک شغل را شروع کن و مینی‌گیم را انجام بده.

۴ بازی را رایگان منتشر کن (تا دیگران هم باز کنند)

وقتی روی GitHub باشد، می‌توانی با Cloudflare Pages یا Vercel رایگان منتشرش کنی.

با Cloudflare Pages (رایگان):

  1. برو به pages.cloudflare.com
  2. حساب رایگان بساز.
  3. Connect to Git → مخزن GitHub خودت را انتخاب کن.
  4. تنظیمات ساخت:
    • Framework: Next.js
    • Build command: npm run build
    • Output: معمولاً خودکار تشخیص داده می‌شود
  5. Save and Deploy. چند دقیقه صبر کن تا لینک عمومی بدهد.

دامنه .ir خودت را بعداً وقتی درآمد داشتی می‌توانی وصل کنی. اول لینک رایگان کافی است.

۵ اسپرایت و صدا (اختیاری ولی قشنگ‌تر می‌کند)

بازی بدون این‌ها هم کار می‌کند. اگر خواستی ظاهر و صدا بهتر شود، فایل راهنمای «دانلود دارایی‌ها» را بخوان.

دانلود از سایت‌های رایگان است؛ بعد فایل‌ها را در GitHub داخل پوشه‌های public/sprites و public/audio آپلود می‌کنی.

اگر گیر کردی

  • صفحه سفید بود → چند ثانیه صبر کن یا یک بار Refresh بزن.
  • StackBlitz بالا نیامد → با موبایل داده کمتر است؛ از لپ‌تاپ و وای‌فای بهتر امتحان کن.
  • کاراکتر ذخیره نشد → در همان مرورگر بمان؛ داده‌ها روی همان دستگاه ذخیره می‌شوند.
یادت باشد: هیچ برنامه‌ای روی لپ‌تاپ لازم نیست. فقط مرورگر + حساب رایگان GitHub و StackBlitz/Cloudflare.
